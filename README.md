# Refine Energy Consulting — Web App

Single-page marketing site for **Refine Energy Consulting (REC)**: building energy optimization for small and midsize commercial property owners in the Sacramento area.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4

## Content

Editable business copy lives in `src/lib/content.ts`. Prefer updating that file rather than hardcoding strings in components.
